## LoginNotify (для модераторов)
**Назначение:** упрощает отслеживание подозрительных игроков в сети.

| Команда | Назначение | Пример |
|---------|------------|--------|
| `/lnn` | Показать все доступные команды | `/lnn` |
| `/lnn list` | Показать список игроков на "учёте" | `/lnn list` |
| `/lnn list online` | Показать только онлайн игроков | `/lnn list online` |
| `/lnn list offline` | Показать только оффлайн игроков | `/lnn list offline` |
| `/lnn add <ник> <описание>` | Добавить игрока в список | `/lnn add Totilak Вонючка` |
| `/lnn remove <ник>` | Удалить игрока из списка | `/lnn remove Totilak` |
| `/lnn toggle` | Включить/выключить уведомления лично для вас | `/lnn toggle` |
| `/matrixshutup` | Отключить сообщения Matrix в чате | `/matrixshutup` |

> Примечание: С версии 1.4.1 список `/lnn list` разбит на страницы для удобства.
> `matrixshutup` начинает действовать со следующего входа игрока.
